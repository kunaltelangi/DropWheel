Get started.

Installed and ready in about a minute.

  1. Download DropWheel.dmg.
  2. Open the DMG and drag DropWheel into your Applications folder.
  3. Right-click the app, choose Open, and confirm Open again.
  4. Allow Accessibility and Input Monitoring when macOS asks.
  5. Launch it, then press fn or ⌥ Space.

Blocked on first launch? DropWheel isn’t notarized by Apple. Open System Settings, go to Privacy & Security, and click Open Anyway.

The details.

What it is
DropWheel is a radial file toolkit for macOS 14 or later, free for personal and noncommercial use. It converts, compresses, renames and sorts images, video, audio, PDFs, documents and archives locally on your Mac.
Shortcuts
fn or ⌥ Space opens the wheel. Press 1–9 to pick an action (0 is the tenth), H for help, ⌘V to paste files or a screenshot, and Esc to go back or close. If fn opens the emoji picker, change the Globe key in Keyboard settings.
Menu bar
Launch at login, choose where results are saved, move originals to the Trash after converting, copy the result, and turn the done sound off.
Permissions
Accessibility lets the app respond to global interactions. Input Monitoring detects the shortcuts. If macOS asks again after an update, run the app from /Applications.
Optional tools
Office conversions need LibreOffice. PDF OCR needs ocrmypdf, installed with brew install ocrmypdf. DropWheel tells you when a tool is missing.
PDF Unlock
Removes owner-password restrictions like printing, copying and editing. It can’t open files that need a password to view.
Distribution
Not on the Mac App Store, because the bundled tools need App Sandbox turned off.
License
PolyForm Noncommercial 1.0.0: free for personal use, study, research, charities, schools and government. Commercial use needs permission. Bundled third-party tools keep their own licenses. See the notices.

Build it yourself.

Needs macOS, Xcode or the Command Line Tools, and Homebrew.

# if you don’t have the tools yet
xcode-select --install

git clone https://github.com/kunaltelangi/DropWheel.git
cd DropWheel

# bundle required tools and generate a DMG
./make-app.sh

# or use tools already on your Mac
./make-app.sh --no-bundle

The app and DMG appear in the build folder. Bundled tools match the architecture of the Mac you build on.

Questions.

Is it safe to open?

The source code is public on GitHub under the PolyForm Noncommercial license, so you can read every line or build the app yourself. It isn’t notarized by Apple yet, which is why macOS asks you to confirm the first launch.

Do my files leave my Mac?

No. DropWheel never uploads your files, and the tools run locally on your Mac. AirDrop and Mail only open when you choose them.

Will it overwrite my originals?

No. Conversions are saved beside your originals or in a folder you choose. An optional setting moves the original to the Trash after a successful conversion. Rename and Sort change names and locations, because that is what they are for.

Why does it need Accessibility and Input Monitoring?

Accessibility lets the wheel respond to global interactions, and Input Monitoring detects the fn and ⌥ Space shortcuts. Nothing else is read.

Why isn’t it on the Mac App Store?

The bundled tools need App Sandbox turned off, which the Mac App Store doesn’t allow.

It won’t run on my Mac. What now?

Bundled tools match the architecture of the Mac they were built on. Building it yourself takes a minute and gives you a version made for your Mac.
