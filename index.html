Press. Drop. Choose.

Hit Fn or ⌥ Space anywhere on your Mac. Drag files onto the wheel and pick an operation. No windows to hunt for, no menus to dig through.

Get started.

Installed and ready in about a minute.

  1. Download DropWheel.dmg.
  2. Open the DMG and drag DropWheel into your Applications folder.
  3. Right-click the app, choose Open, and confirm Open again.
  4. Allow Accessibility and Input Monitoring when macOS asks.
  5. Launch it, then press Fn or ⌥ Space.

Blocked on first launch? DropWheel isn’t notarized by Apple. Open System Settings, go to Privacy & Security, and click Open Anyway.

The details.

Shortcuts
Fn or ⌥ Space
Permissions
Accessibility lets the app respond to global interactions. Input Monitoring detects the shortcuts. If macOS asks again after an update, run the app from /Applications.
Office files
Spreadsheet, presentation and Office to PDF conversion needs LibreOffice.
PDF OCR
Needs ocrmypdf. Install it with brew install ocrmypdf. DropWheel tells you when an optional tool is missing.
PDF Unlock
Removes owner-password restrictions like printing, copying and editing. It can’t open files that need a password to view.
Distribution
Not on the Mac App Store, because the bundled tools need App Sandbox turned off.
License
MIT. Bundled third-party tools keep their own licenses. See the notices.

Build it yourself.

Needs macOS, Xcode or the Command Line Tools, and Homebrew.

# if you don’t have the tools yet
xcode-select --install

git clone https://github.com/kunaltelangi/DropWheel.git
cd DropWheel

# bundle required tools and generate a DMG
./make-app.sh

# or use tools already on your Mac
./make-app.sh --no-bundle

The app and DMG appear in the build folder. Bundled tools match the architecture of the Mac you build on: use Apple Silicon for Apple Silicon, Intel for Intel.
