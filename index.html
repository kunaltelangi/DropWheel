Get started.

Installed and ready in about a minute.

  1. Download DropWheel.dmg.
  2. Open the DMG and drag DropWheel into your Applications folder.
  3. Right-click the app, choose Open, and confirm Open again.
  4. Allow Accessibility and Input Monitoring when macOS asks.
  5. Launch it, then press Fn or ⌥ Space.

Blocked on first launch? DropWheel isn’t notarized by Apple. Open System Settings, go to Privacy & Security, and click Open Anyway.

The details.

Shortcuts
Fn or ⌥ Space opens the wheel. Press 1–9 to pick an action (0 is the tenth), H for help and Esc to close. If Fn opens the emoji picker, change the Globe key in Keyboard settings. The menu bar has a shortcut to it.
Requirements
macOS 14 or later.
Menu bar
DropWheel lives in the menu bar. There you can launch it at login, choose where results are saved, move originals to the Trash after converting, and turn the done sound off.
Permissions
Accessibility lets the app respond to global interactions. Input Monitoring detects the shortcuts. If macOS asks again after an update, run the app from /Applications.
Office files
Spreadsheet, presentation and Office to PDF conversion needs LibreOffice.
PDF OCR
Needs ocrmypdf. Install it with brew install ocrmypdf. DropWheel tells you when an optional tool is missing.
PDF Unlock
Removes owner-password restrictions like printing, copying and editing. It can’t open files that need a password to view.
Distribution
Not on the Mac App Store, because the bundled tools need App Sandbox turned off.
License
MIT. Bundled third-party tools keep their own licenses. See the notices.

Build it yourself.

Needs macOS, Xcode or the Command Line Tools, and Homebrew.

# if you don’t have the tools yet
xcode-select --install

git clone https://github.com/kunaltelangi/DropWheel.git
cd DropWheel

# bundle required tools and generate a DMG
./make-app.sh

# or use tools already on your Mac
./make-app.sh --no-bundle

The app and DMG appear in the build folder. Bundled tools match the architecture of the Mac you build on: use Apple Silicon for Apple Silicon, Intel for Intel.

Questions.

Is it safe to open?

DropWheel is open source under the MIT license, so you can read every line on GitHub or build the app yourself. It isn’t notarized by Apple yet, which is why macOS asks you to confirm the first launch.

Do my files leave my Mac?

No upload step is needed. The conversion tools are bundled inside the app and run locally on your Mac.

Will it overwrite my originals?

By default, never. Results are saved beside your originals or in a folder you choose. An optional setting moves the original to the Trash after a successful conversion.

Why does it need Accessibility and Input Monitoring?

Accessibility lets the wheel respond to global interactions, and Input Monitoring detects the Fn and ⌥ Space shortcuts. Nothing else is read.

Why isn’t it on the Mac App Store?

The bundled tools need App Sandbox turned off, which the Mac App Store doesn’t allow.

It won’t run on my Mac. What now?

Bundled tools match the architecture of the Mac they were built on. Building it yourself takes a minute and gives you a version made for your Mac. See the steps above.
